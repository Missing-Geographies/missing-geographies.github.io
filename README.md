# Missing Geographies — Globe Starter

This is a beginner starter folder for the interactive audio globe.

## What each file does

- `index.html` = the web page structure
- `styles.css` = colors, layout, glowing points, and visual style
- `script.js` = the globe, story data, clickable points, audio, and connection lines
- `assets/audio/` = where voice files go

## How to add a real story later

Open `script.js` and edit the `stories` list near the top.

Each story needs:

- title
- origin city/country
- origin coordinates
- destination city/country
- destination coordinates
- year left
- quote
- audio file path

Example audio path:

`assets/audio/story-001.wav`

For real stories, MP3 files are usually better than WAV because they are smaller.
